# 更新日志

## 新增功能

- 新增 Windows 原生 AWA-Manager.exe 托盘入口，支持后台启动、实时任务状态、打开管理页面和日志目录、Helper/Achievement 启停、当前用户开机自启和安全退出。
- 新增 Windows 原生安装与更新器，支持完整性检查、缺失文件安装或修复、检查更新、下载源回退、SHA-256 校验、安装备份、失败回滚及中断恢复；保留用户配置和运行数据。
- 新增 Battle Pass 奖励自动领取，通过 awaQuests 中的 battlePass 启用，默认关闭；WebUI 和结果推送展示进度与领取结果。
- 新增“运行记录与诊断”页面，展示运行历史、子任务结果、连续失败次数及未来五次计划时间，支持 Cron 预览和调度时区设置。
- 新增 AWA、Twitch、ASF 连接与授权诊断，以及脱敏诊断 JSON 导出；运行历史持久化，异常退出后的记录标记为中断。
- Manager 密钥为空时自动生成并保存随机密钥；WebUI 支持选择记住密钥。
- 新增 Steam 社区挑战游戏信息管理，可在首页填写游戏 ID 和可选名称、查看更新时间，并从 GitHub 或内置代理来源同步；数据独立保存于当前 config.yml 同目录的 community-event.json。

## WebUI 与日志

- 统一 Manager 与任务 WebUI，集中管理每日任务、成就和遗物任务，优化首页布局、状态展示、按钮和移动端样式。
- 新增独立登录页，校验 Manager 密钥后再进入面板，支持记住密钥、返回原访问页面和退出登录；未登录或验证期间不显示面板内容，密钥失效时自动返回登录页，连接失败时支持重试。
- 统一首页、每日任务、设置及运行记录页面的导航和公共样式，优化任务卡片、信息层级及响应式布局。
- 将 Steam 社区活动信息表单整合到 DailyQuest 控制区域，增加醒目的中英文提示，说明新版活动页面需要远程同步或手动填写游戏 ID。
- 重做设置页分组导航、表单布局、输入校验与保存反馈，支持加载重试，保留模板之外的配置字段。
- 优化日志预览弹窗，支持分页、查看较早内容、跳转最新内容，以及文件轮换和空状态提示。
- 修复日志不同步、分类错误、对象日志显示异常、乱码及 Docker 日志颜色丢失问题。
- 优化 WebSocket 重连、日志回放、缓存及实时日志数量限制，降低长时间运行时的资源占用。
- 新增日志总容量预算 logsMaxMB，完善按日期与容量清理策略，保护当天及正在写入的日志。
- 新增可选 HTTP 调试日志，记录请求地址、状态码及耗时，并过滤凭据与查询参数。

## 配置与运行优化

- 统一任务调度、作业协调和状态管理，每日任务、成就及遗物任务接入同一 Manager 运行模型。
- 配置保存前执行完整结构和语义校验；WebUI 保存后重载配置，更新调度计划和动态参数，监听配置变化时提示重启。
- 修复 Cookie 更新不生效；油猴脚本适配新 API，AWA Cookie 同步支持更新 User-Agent，AWA/Twitch Cookie 写入后触发配置重载。
- 优化任务刷新 Cookie 的保存逻辑，避免覆盖用户在运行期间写入的新 Cookie；新任务读取最新配置，运行中的任务保留本次配置。
- 优化缺失配置、无效 YAML 和配置校验失败的提示；自动生成密钥时仅更新对应 YAML 字段。
- 重做更新流程，下载校验后等待进程退出再安装，协调托盘与独立 Helper 的更新锁；清理已完成的更新暂存目录并保留最近一次成功备份。
- 优化结果推送格式、Battle Pass 汇总和失败信息，减少重复推送。
- 结果推送过滤已结束、已关闭、尚未开始或无可用 ARP 的社区活动，减少无效内容。
- 社区挑战游戏信息按运行机器本地年月校验有效性；启用 joinSteamCommunityEvent 且活动开放、个人时长未完成时，缺失或过期信息自动从所选来源同步，仍无有效信息则跳过并提示补充。
- 社区挑战信息采用原子写入，远程同步失败保留已有数据；任务自动同步时检测期间发生的本地修改，避免覆盖新保存的信息。
- 仓库新增供远程同步读取的 community-event.json，提供 2026 年 9 月的社区活动游戏信息 Aniimo（游戏 ID：4126040）。
- 调整任务停止时的网络请求处理，停止后不再发起新请求或重试，已发出的普通请求等待结束；超时通知和 ASF 停止游戏操作保留独立请求期限。
- 优化共享网络请求、日志缓存和资源清理，新增资源基准与长时间运行检查脚本。

## 问题修复

- 适配新版 Steam 社区挑战页面，分别识别游戏拥有状态和活动加入状态，兼容新的同步按钮，避免将已拥有游戏误判为已加入活动。
- 社区挑战游戏同步接口改用 sync-owned-games，并兼容 installed 和 success 响应字段；游戏信息改从独立数据文件读取，适配页面不再提供游戏启动链接的变化。
- 修复从 WebUI 终止 Manager 后托盘仍驻留的问题，Manager 正常退出后同步关闭托盘；异常退出时保留图标与错误提示以便排查。
- 修复新版每日任务 ARP、部分任务完成状态识别错误，以及任务完成后仍继续运行的问题。
- 修复任务结束后超时定时器未清理，导致延迟发送错误超时通知的问题。
- 修复 Twitch 无可用直播或追踪频道时意外退出，改为定时重试；优化网络错误重试和 ARP 到账等待。
- 修复 Twitch 成就任务未发送直播心跳、Achievement 启动报错及代理配置问题。
- 修复成就任务重复定时器、异常丢失、UTC 与本地日期混用、失败后错误记录历史和历史文件写入问题。
- 修复遗物 ID 数量、重复值和非正整数校验，以及可能错误报告任务成功的问题。
- 修复异步等待遗留 AbortSignal 监听器的问题。
- 改用原子进程锁，修复锁创建竞争并支持崩溃后的陈旧锁恢复；Docker 环境不再创建进程锁。
- 修复 Docker 中受 webUI.local 限制而无法通过端口映射访问的问题，容器内统一监听 0.0.0.0。
- 健康检查改为实际服务与进程探测，并提供独立的 Docker 健康检查入口。

## 安全

- 统一 API Bearer 鉴权，本地和远程 WebSocket 均校验 Manager 密钥；密钥变更后断开已有 WebSocket 会话。
- 增加 WebSocket 连接和消息限制，完善错误处理与日志访问鉴权。
- 新增 /api/auth 登录校验接口及各页面统一鉴权处理；登录返回地址限制为已知站内页面，社区挑战信息读写与同步接口同样要求 Bearer 鉴权。
- 统一日志与诊断脱敏，避免错误输出泄露 Cookie、密码、Token 和请求头。
- Battle Pass 领取请求限制为 AWA 同源地址，并校验 CSRF Token、响应状态及里程碑 ID。
- 加强更新包校验、解压路径和程序文件范围限制；Docker 改用非 root 用户运行，更新相关依赖。
- Manager 密钥少于 16 个字符时输出警告，不阻止启动。

## 升级注意事项

- WebUI 与 Manager 服务统一，默认端口调整为 2345；使用旧端口映射或反向代理的部署需同步检查配置。
- 程序入口由 main.js 改为 index.js，默认启动常驻 Manager；--daily 执行一次每日任务后退出，--helper 保留为兼容别名。
- 新配置使用 manager，定时字段统一为 cron，遗物 ids 使用数字数组；加载时仍规范化部分旧 managerServer、corn 和字符串 ID 配置，建议按新模板迁移。
- 移除旧 Manager API、旧页面路径和请求体密钥兼容，统一使用 /api/* 与 Bearer 鉴权；旧 /getConfig、/setConfig 由 /api/config 替代，外部调用方需更新。
- 统一 Achievement 拼写，移除 Archievement 对应的旧页面、接口、标识符、数据目录及日志前缀兼容，升级时需检查旧数据路径。
- Node.js 版本要求调整为 ^22.20.0 || ^24.12.0 || >=26.0.0，源码运行和自行构建时需使用受支持版本。
- 示例配置默认关闭自动更新、Twitch 和 Steam 任务；启用任务前需配置所需凭据，Battle Pass 也需手动启用。
- Windows 原生安装与修复依赖新版发行包的 installation.json 清单，旧发行包无法用于该流程。
- Docker 使用 node 用户运行，挂载的 config、logs、data 目录需允许该用户读写。
- 社区挑战的游戏信息不写入 YAML，备份或迁移时需一并保留 community-event.json；信息仅在对应年份和月份内有效，可通过首页手动更新或远程同步。

## 架构、构建与文档

- 重构为 CLI、平台客户端、核心服务、统一服务器、工具和 WebUI 分层架构，拆分 AWA、Steam ASF、Twitch 的 API、解析器、类型与错误处理。
- 拆分每日任务运行时、状态、报告器和各类任务模块，统一 HTTP、Cookie、代理、配置、日志、通知及更新能力。
- WebUI 脚本迁移至 TypeScript，调整静态资源构建并移除旧前端构建依赖。
- 将首页和设置页图标及共用 favicon 提取为独立 SVG/ICO 资源，在构建时内联到页面；补充 ICO 类型识别，减少页面源码中的重复图标内容。
- 更新 Windows SEA、原生托盘、Linux、Docker 打包及 Release 流程，Windows 发行包新增文件清单与校验文件。
- 新增 build:test 命令，执行前置构建与 Windows 可执行文件打包，跳过完整发行构建中的 UPX 压缩和归档步骤。
- 调整 lint、类型检查、测试和构建验证命令，CI 扩展为 Windows/Linux 与 Node.js 22、24、26 矩阵，并加入 Windows 安装与恢复测试步骤。
- 新增基于 VitePress 的中英文文档站点，补充快速开始、运行方式、WebUI、配置参考、架构说明和 Windows 更新器文档。
- 补充中英文社区挑战游戏信息配置、远程来源与有效期说明，并更新 WebUI 关闭 Manager 后的托盘退出行为说明。
- 更新中英文配置文档中的社区活动表单位置说明，统一相关客户端、WebUI、构建脚本及语言资源的中文注释。
