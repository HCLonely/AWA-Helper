### Features

- feat: 新增 Battle Pass 自动领取功能，并在 DailyQuest WebUI 和每日推送中显示完成状态与代币进度
- feat: 将 Manager WebUI 默认端口调整为 2345，并同步健康检查、Docker、配置模板和文档
- feat: Manager 密钥少于 16 个字符时输出安全警告，但不阻止程序启动
- feat: 优化 Manager WebUI，集中管理每日任务、成就任务和遗物任务
- feat: 优化任务调度器、作业协调器和状态存储，支持按 Cron 表达式运行各类任务
- feat: 统一 HTTP/WebSocket 服务及任务状态、控制、日志和配置接口
- feat: 新增 CLI 命令解析，支持初始化、健康检查及不同运行模式
- feat: 优化 AWA、Steam ASF 和 Twitch 的独立 API、会话及上下文客户端
- feat: 优化 Manager、DailyQuest 和 Achievement 分类日志查看功能

### Breaking Changes

- breaking: 移除仅校验 YAML 语法的旧 `/getConfig` 和 `/setConfig` 接口，设置页改用经过完整结构校验的 `/api/config`
- breaking: 移除所有 Achievement 错误拼写对应的页面、接口、标识符、数据目录和日志前缀兼容逻辑
- breaking: WebSocket 在本地和远程模式下均要求提供有效的 Manager 密钥

### Bug Fixes

- fix: 修复 Docker 容器内受 `webUI.local` 限制而无法通过端口映射访问 WebUI 的问题
- fix: 修复每日任务结束后超时定时器未清理，可能延迟发送错误超时通知的问题
- fix: 修复旧配置写入接口可绕过完整配置校验并写入无效配置的问题
- fix: 修复遗物任务接受数量错误、重复或非正整数 ID，并可能错误报告成功的问题
- fix: 统一修正代码、WebUI、API、国际化资源和兼容逻辑中的 Achievement 拼写
- fix: 修复无可用 Twitch 直播或追踪频道时任务意外退出的问题，改为定时重试
- fix: 修复对象类型日志显示为错误字符串的问题
- fix: 修复 WebUI 日志内容及任务日志分类不同步的问题
- fix: 修复 WebUI 日志按钮未正确校验 Manager 密钥的问题
- fix: Docker 容器环境不再创建进程锁，避免容器重启后出现锁冲突

### Security

- security: Battle Pass 领取请求限制为 AWA 同源地址，并校验 CSRF Token、响应状态及里程碑 ID
- security: WebSocket 连接统一校验 Manager 密钥，避免本地日志被跨站连接读取
- security: 对弱 Manager 密钥增加启动警告，并补充中英文提示和配置文档

### Refactoring

- refactor: 将项目重构为 CLI、客户端、核心服务、服务器、工具和 WebUI 分层架构
- refactor: 将 AWA、Steam 和 Twitch 客户端拆分为独立 API、解析器、类型及错误处理模块
- refactor: 抽离共享 HTTP 传输、Cookie、代理、Result 和平台错误处理能力
- refactor: 将每日任务拆分为运行时、状态、报告器及 Daily、Legacy、Steam、Twitch 和在线时长任务
- refactor: 将 Achievement、Artifact 和 DailyQuest 接入统一 Manager 作业模型
- refactor: 将日志、配置、HTTP、代理、通知、更新、进程及国际化能力拆分为独立工具模块
- refactor: 统一 API 调用结果和响应解析，减少平台客户端中的重复业务逻辑
- refactor: 重组 WebUI 页面、脚本、配置模板和静态资源目录
- refactor: 将程序入口由 `main` 调整为 `index`
- refactor: 将 Manager 配置迁移至新的 `manager` 配置结构，并规范 Cron 和遗物 ID 格式
