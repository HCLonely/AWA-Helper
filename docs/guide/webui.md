# WebUI 与日志

## 连接 Manager

启动 Manager 后访问默认地址 `http://127.0.0.1:2345`，在首页填写并保存实际配置文件中的 `manager.secret`。勾选记住密钥会将其保存在当前浏览器的本地存储中；否则只在当前会话中保存。

首页可启动或停止 Helper（DailyQuest）与 Achievement、查看状态、打开日志、更新程序或停止 Manager。启动请求被接受不代表任务已完成，请结合状态和日志查看结果。

## 修改设置

1. 在首页保存 Manager 密钥后进入设置页。
2. 页面自动加载内置设置模板和服务器当前配置，通过顶部菜单选择配置分组。
3. 修改开关、选项和输入框；数组或对象列表可按模板提供的操作添加、删除条目。
4. 点击当前分组的保存按钮。页面会先进行输入校验，服务器再校验完整配置。
5. 如果提示服务器设置需要重启，请重启 Manager；端口或 HTTPS 修改后使用新地址访问。

编辑过程中不会自动保存。保存以当前配置为基础，保留模板之外的字段；表单保存会重新序列化配置，不保留原 YAML 注释和排版。如果加载失败，请检查密钥、连接和错误提示，再使用重试按钮。

设置页还支持选择或拖入本地**设置模板**，或填写远程模板 URL。这些文件用于定义编辑表单，不能把普通 `config.yml` 当作模板导入。

## 配置何时生效

| 修改方式或内容 | 生效行为 |
| --- | --- |
| WebUI 保存配置 | 写入后重新加载配置，并更新调度计划和动态运行参数 |
| 修改 WebUI 启用状态、端口、监听范围或证书配置 | 保存后提示需要重启 Manager |
| 修改 Manager 密钥 | API 使用新密钥，已有 WebSocket 会话会断开；其他浏览器和用户脚本也需更新密钥 |
| 修改任务凭据、任务选项或代理 | 新任务启动时读取最新配置；正在运行的任务保持本次运行的配置 |
| 直接编辑磁盘配置 | 下一次任务启动会读取文件；调度器和 WebUI 等进程级配置需重启 Manager 或通过 WebUI 保存触发重新加载 |

用户脚本提交 AWA Cookie 时还可同步 User-Agent；AWA 与 Twitch Cookie 接口写入后都会触发配置重新加载。任务内部刷新出的 AWA Cookie 也会尝试保存，但不会覆盖运行期间用户另行写入的新 Cookie。

## 查看日志

- 日志位于运行目录的 `logs/`，按 Manager、DailyQuest、Achievement、Artifact 和日期区分。
- 任务页面通过 WebSocket 展示近期实时日志；为了控制浏览器占用，实时视图有显示上限。
- 日志预览在弹窗中按页读取文件，默认显示最新内容。使用“较早内容”向前翻页，使用“最新内容”重新读取末尾。
- 日志文件轮换后，预览会提示并重置读取位置；没有日志时显示空状态。预览需要 Manager 在线及有效密钥。
- 更早日期的日志可直接从 `logs/` 查看；保留时间与总容量见[配置文件](/reference/configuration)。

## 常见问题

| 现象 | 检查方法 |
| --- | --- |
| Manager 已启动，但 Helper 没有运行 | 常驻模式等待 Cron 触发，可在首页手动启动 Helper |
| 设置或日志提示未授权 | 核对当前加载配置中的 `manager.secret`，重新保存密钥 |
| Cookie 同步成功但本次任务仍报认证失败 | 确认用户脚本使用当前 API；停止并重新启动任务以读取新 Cookie |
| 修改配置后没有变化 | 检查配置路径优先级，确认已保存；服务器设置需要重启 |
| 日志容量超过 `logsMaxMB` | 当天及正在写入的日志受保护，预算不是硬性文件大小上限 |
| 在线任务发生短暂网络错误 | AWA 在线心跳错误计数达到 6 后会等待 5 分钟再重试；Twitch 心跳的可重试网络错误也有重试等待，先结合日志判断是否仍在恢复 |

## 运行历史与诊断

从 Manager 首页进入独立的“运行记录与诊断”页面（`/operations`），可查看最近运行、子任务结果、连续失败次数和未来五次计划时间。进入页面自动读取记录，也可点击“刷新记录与计划”更新显示；记录时间使用浏览器本地时区，计划时间使用该计划的时区。

```yaml
manager:
  # timezone: Asia/Shanghai  # 留空或省略时使用系统时区
  historyLimit: 200         # 10–1000，重启生效
```

- 历史保存在运行目录的 `data/manager/history.json`，默认保留最近 200 条。异常退出留下的运行记录在下次启动时标为中断；历史文件损坏时保留原件并在运行记录页面显示存储错误。
- “检查连接”仅检查平台连接及授权，不执行任务：AWA 会话与控制中心结构、Twitch 扩展授权、ASF IPC 状态。结果区分 Cookie 失效、扩展缺失、限流、页面变化和连接失败，并提供下一步。相同配置的诊断结果缓存 30 秒。
- “导出脱敏诊断”下载 JSON，包含版本、运行环境、最近 50 次运行、上次诊断结果和当天四类日志的末尾片段（每类最多 64 KiB）。导出不主动重新检查连接，也不包含完整配置或原始页面。
- Cron 预览不会修改配置。五段表达式省略秒，六段包含秒；日期和星期同时指定时需同时匹配。跨时区及夏令时请以预览显示的实际时间为准。
